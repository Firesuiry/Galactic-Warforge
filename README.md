# SiliconWorld

**一句话定位**
一款由 AI Agent 协同驱动的多人星际工业战争游戏：戴森球式的工厂 + RTS 式的大混战，在三层宇宙地图中展开探索、扩张与混战。

**核心概念**
- 星际题材的工业建造 + 战争对抗；战斗力 = 产能 × 补给，单位和弹药都由产线生产
- 三层宇宙地图：星系层 / 恒星系层 / 星球层；行星是封闭的六面立方体球面
- 服务端权威、Tick 驱动结算；HTTP + SSE + 命令接口驱动，客户端以指挥、看板与 Agent 协作为主
- 多玩家 / 阵营对抗，对手包括黑雾（PvE）、遭遇战 bot 与其他玩家
- AI Agent 是一等公民：可授权自治、可审计、可回收；服务端不区分人类命令和 AI 命令

**核心玩法循环**
1. 立足生存：采集、发电、冶炼、制造，建立基础基地与防御
2. 自动化扩张：完善工业链与物流网络，跨星体扩展
3. 科技突破：主科技树推进，逐步进入太阳帆与戴森结构
4. 军事博弈：多兵种地面大混战、军团指挥、弹药补给线争夺；后期舰队与跨星战争
5. AI 协同：从“下达命令”转为“设定目标、授予权限、监督结果”

**世界结构**
- 星系层：远征与全局战略、长距离航线与战略控制点
- 恒星系层：行星开发、轨道封锁、运输与舰队作战
- 星球层：基地建设、资源采集、地面战斗与前线推进

**AI Agent 设计**
- 经济型：补建与产线平衡、资源调度、科研物资保障
- 军事型：侦察、防御补位、威胁评估与部队调度
- 探索型：规划远征与标注资源富集点
- 总指挥型：综合经济、科技、军事的全局决策

**技术原则**
- 整个项目完全交由 AI 开发
- 每个版本之间不做任何兼容性保证，不会主动兼容过去的内容
