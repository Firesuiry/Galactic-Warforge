# 摆放与产线连接（实测规则）

本页规则都在真服务端上实测过。示例坐标来自存档点构建记录（地图 `skirmish-seed-001`），每轮 checkpointbuild 都会回放验证。换地图时，坐标要按同样的相对关系平移。

## 1. 坐标：`build x y` 是占地左上角

- `x`、`y` 是占地的**左上角**格子，占地向东（+x）、向南（+y）展开。不是中心。
- 例：电弧熔炉 3×3 建在 `(62,140)`，占 x 62–64、y 140–142。这时 `build 63 141 wind_turbine` 返回 `POSITION_OCCUPIED 该格已有你的建筑：电弧熔炉`。
- 所有建筑的占地都是正方形，所以 `--rotation` 不改变占地。
- 占地大小用 `catalog building <id>` 查。常用的：

| 建筑 | 占地 | 备注 |
| --- | --- | --- |
| `mining_machine` 采矿机 | 3×3 | 占地加外 1 圈要覆盖矿点 |
| `arc_smelter` 电弧熔炉 / `assembling_machine_mk1` 制造台 / `matrix_lab` 研究站 | 3×3 | 进、出料都要分拣器 |
| `supply_station` 补给站 | 3×3 | 开局就能建，容量 1000；做产线终点 |
| `depot_mk1` 小型储物仓 | 3×3 | 要先研究「电磁学」 |
| `wind_turbine` 风力涡轮机 | 2×2 | 发电 10 |
| `tesla_tower` 电力感应塔 | 1×1 | 供电半径 12 |
| `conveyor_belt_mk1` 传送带 / `sorter_mk1` 分拣器 | 1×1 | |
| `battlefield_analysis_base` 基站 | 5×5 | 建造半径 72 |

## 2. 分拣器：朝向 = 放货方向，背面取货

- `--rotation` 就是**正面（放货）方向**：`0` 北（y−1）、`90` 东（x+1）、`180` 南（y+1）、`270` 西（x−1）。正对的反方向是**背面（取货）**。
- 分拣器沿背面、正面两条轴各向外扫描**最多 3 格**：跳过空格，停在遇到的**第一个建筑**上。
  - 取货端：一段传送带（任意格），或带输出口、有存储的建筑（熔炉、制造台、矿机、补给站……）。
  - 放货端：一段传送带（可以从侧面放上去），或带输入口、有存储的建筑。
  - 轴上先碰到别的分拣器，或者碰到不收货的建筑，就到此为止，这一端判为无效。
- **扫描轴上的第一栋建筑就是端点**。哪怕更远的地方有更合适的传送带，只要中间先扫到熔炉（它同时有输入口和输出口），取货端就是熔炉。所以摆分拣器时，要把「轴上第一栋」算准；对不准就挪一格。
- **两端都有效才会搬运**。只要有一端无效，它就一直不动，也不会发 `sorter_stalled` 告警。
- 所以分拣器建成后要**立刻看回执和 `inspect`**：
  - `build` 回执会追加两端预判，例如 `取货端：b-124 传送带 Mk.I（东 2 格），放货端：b-55 电弧熔炉（西 2 格）`，或者 `放货端：未连上——东侧 1 格是分拣器 b-118，挡住了`；
  - `inspect <分拣器ID>` 有一行 `sorter`，例如 `取←西 b-101 传送带 Mk.I(1格) | 放→东 b-105 补给站(1格)   last=t7427 iron_ingot b-101→b-105`。
  - `last=-` 表示还没有搬运过；如果两端都显示连上了、货也有，等 20 tick 再看一次。
  - 预判会把**还在施工队列里的建筑**也算进去（标成「施工中，任务 c-7」），但不模拟它们落成后是否通电。
- 分拣器只能建在地面层（`--elevation` 给分拣器会报 `INVALID_ELEVATION 只有传送带可以架高`）。
- 物品过滤：`configure_sorter <id> --mode allow --items iron_ore`。

## 3. 传送带只运货，不给建筑喂料

- `--direction north|east|south|west` 指**出货方向**，入口在反方向。
- **传送带不会把货送进熔炉、制造台或研究站**。实测带子直接对着熔炉，带上的矿一直堵着（`blocked_ticks` 上千），熔炉一个都没收到。这类生产建筑的进料和出料都必须经过分拣器。
- 带子没有存储，`transfer` 装不进去（`目标建筑没有存储`）。
- 能直接往带子上吐货的只有**直出建筑**（目录里 `direct_belt_io`）：采矿机、抽水机、抽油机、轨道采集器、分流器等。条件是带子**贴着占地边缘**，而且带子的出货方向**背离**这个建筑。
- 架高（`--elevation 1-4`）只给传送带用，必须写明 `--direction`，用来跨过别的带子。详见 `docs/guide/传送带与分拣器DSP对齐.md`。
- **拐弯要单独占一格**：带子只能直行，想转向就在拐角放一格出货方向指向新方向的带子。
- **直出必须紧贴占地边缘那一格**：采矿机和带子之间隔一格，货就吐不上去。

## 4. 采矿机

- 3×3 占地加外 1 圈里必须有矿点，否则报 `INVALID_TARGET mining_machine 占地及外圈没有可开采的资源节点`。用 `scene` 看矿点位置。
- 采哪种矿在下单时就定了：取覆盖范围里格数最多的那种（平票取 ID 较小者），回执里会写「将开采『X』」。
- 出货方式只有两种：直出到贴边且背离的传送带上，或者用 `transfer <矿机ID> iron_ore N --take` 手动取。**没有出口的矿机，几 tick 就会被自己的产出堵死。**

## 5. 生产建筑的原料窗口

分拣器和手动 `transfer` 往熔炉、制造台里装料时，每种原料最多只收**配方用量的 2 倍**。例如电磁矩阵要磁线圈 1 + 电路板 1，每次就只能各装 2 个。少量手动喂料要反复装；长期运行就用分拣器，从补给站或传送带上取料。

## 6. 产线模板（坐标为实测值）

### 6.1 铁矿 → 熔炉 → 补给站（cp-mining 的原始布局）

> 这组坐标只对 cp-mining 有效。cp-base 上同一位置已经被占用，要先用 `scene` / `find_space` 另找空地，再按下面的相对关系摆。

```text
build 57 140 mining_machine                         # 占 57–59 × 140–142，压铁矿
build 60 141 conveyor_belt_mk1 --direction east     # 贴着矿机东边，出货方向朝东（背离矿机）
build 61 141 sorter_mk1 --rotation 90               # 背面（西）取带子 (60,141)，正面（东）放进熔炉
build 62 140 arc_smelter --recipe smelt_iron        # 占 62–64 × 140–142
build 63 143 sorter_mk1 --rotation 180              # 背面（北）取熔炉 (63,142)，正面（南）放到带子 (63,144)
build 63 144 conveyor_belt_mk1 --direction south
build 64 144 sorter_mk1 --rotation 90               # 背面（西）取带子 (63,144)，正面（东）放进补给站
build 65 143 supply_station                         # 占 65–67 × 143–145
```

验证：`inspect` 熔炉显示 running，`inspect` 补给站的铁块持续增长（实测 72 → 278）。

### 6.2 制造台 → 研究站（cp-matrix-line）

```text
build 62 151 assembling_machine_mk1 --recipe electromagnetic_matrix   # 占 62–64 × 151–153
build 65 151 sorter_mk1 --rotation 90           # 背面（西）取制造台，正面（东）放到带子 (66,151)
build 66 151 conveyor_belt_mk1 --direction north
build 66 150 conveyor_belt_mk1 --direction west
build 65 150 conveyor_belt_mk1 --direction west
build 64 150 conveyor_belt_mk1 --direction west
build 63 150 conveyor_belt_mk1 --direction west # 带尾
build 63 149 sorter_mk1 --rotation 0            # 背面（南）取带尾，正面（北）放进研究站 (62,146)
build 66 152 tesla_tower
# 原料：transfer <制造台> magnetic_coil 2 / circuit_board 2，反复装（原料窗口见第 5 节）
```

研究站不设配方，就是研究模式，只收矩阵。

### 6.3 制造台出料 → 补给站（同一列）

```text
# 制造台 (58,153) 占 58–60 × 153–155，补给站 (58,159) 占 58–60 × 159–161
build 58 157 sorter_mk1 --rotation 180   # 背面（北）跳过 1 个空格取制造台，正面（南）跳过 1 格放进补给站
```

扫描会跳过空格，所以中间留 1–2 个空格也能连上。

### 6.4 两种原料进一个制造台

每种原料各用一个分拣器，背面对着原料来源（放着铁块的补给站，或者传送带），正面对着制造台。这些分拣器不能在同一条轴上互相挡住。从补给站取料时，补给站里有多种货，用 `configure_sorter --mode allow --items <物品>` 限定只搬需要的那一种。

## 7. 供电

- **发电**：风力涡轮机每台 10。
- **用电**（`catalog building <id>` 可查）：电弧熔炉 4、制造台 Mk.I 5、矩阵研究站 4、采矿机 2、补给站 2、分拣器 1；电力感应塔本身不耗电。
- **接入电网**：用电建筑距离任一电网节点在供电半径内即可。半径：电力感应塔 12、无线输电塔 18、卫星配电站 30；节点之间用电线连接，最长 3 格。
- **查看**：`networks` 列出每个电网的发电和用电，以及没接上电、电不够的建筑。
  - 发电建筑（风机等）在「Coverage」里显示 `no` 是正常的，因为它本身不耗电；只看用电建筑的 `connected`。
- **建筑没电**时，`inspect` 能看到原因：
  - `power_out_of_range`：离电网太远，在旁边补一座感应塔；
  - `power_no_provider`：网里没有发电，补风机；
  - `under_power`：电不够，加发电或者减少用电。

## 8. 下单前怎么找空地

1. **`find_space <宽> <高> [--count N]`**：直接给出全空矩形，按离机甲由近到远排。它会排除建筑实际占地、地面单位和未落成的施工任务。找一块 3×3 就是这么一条：
   ```bash
   scripts/sw find_space 3 3 --count 3
   # 空地 3x3 @ (62,146)  距机甲 4  地形 buildable
   ```
   跨球面缝的矩形会跳过，窗口边界外的也跳过。
2. `scene`：默认以我的机甲为中心的 48×48 窗口，列出建筑（含锚点和占地）、按种类汇总的矿点、单位。
   - **文本输出默认只列前 20 栋建筑**，超出时末尾会提示；要全量用 `--limit all`，要原始数据用 `--json`。
   - `--json` 里 `buildings` 是对象（key 是建筑 ID），不是数组。
2. 用 `catalog building <id>` 拿到占地 w×h，算出 `[x, x+w) × [y, y+h)`，这一整块都不能碰到已有建筑、施工任务（`planet_runtime --mine`）或地面单位。
3. 不要把建筑贴着单位围一圈：会触发围死判定，报 `INVALID_TARGET 会把…堵死/切断通路`，消息里的坐标就是最后的通道。
4. 超出基站覆盖范围（72）时，机甲必须在 18 格内，否则 `OUT_OF_RANGE`。

## 9. 反例：分拣器全部没连上（上一轮试玩）

- 熔炉 `(14,159)` 占 14–16 × 159–161，补给站 `(17,159)` 占 17–19 × 159–161，两者紧贴。
- 三个分拣器分别放在 `(16,158)` 朝东、`(17,158)` 朝西、`(20,159)` 朝西：
  - 前两个在 y=158 这一行，熔炉和补给站都从 y=159 开始，所以扫描轴碰不到它们；
  - 而且这两个分拣器正好面对面，互相挡住；
  - 第三个背面朝东，扫到的是空地。
- 结果是一件货都没搬，也没有任何告警。
- 正确做法：熔炉和补给站之间空出 1 格，分拣器放在这一格里，背面对熔炉、正面对补给站。也可以分拣器放在熔炉南边、朝南，接一段传送带，再用第二个分拣器送进补给站。
- 现在这种情况在 `build` 回执里就能看出来：`放货端：未连上——东侧 1 格是分拣器 b-181，挡住了`。
