# M1 客户端任务简报（C1 RTS 操作 / C2 3D 战斗表现 / C3 局势感知）

目标文档：docs/guide/缺失内容清单.md 第 10 节。本文给出服务端协议现状与既有代码侦察结论。

## 服务端协议（已实现，直接用）

### 单位实时战斗字段（shared-client/src/types.ts Unit）
- `move_speed`（格/tick）、`path`（含起点的完整路径）、`path_index`、`move_progress`：客户端按 path+move_speed 插值，快照校准。
- `stance`：idle/moving/attack_move/patrol/guard/hold/follow/retreat。
- `attack_target`、`order_pos`、`guard_target_id`、`last_attack_tick`、`attack_cooldown_ticks`、`aggro_range`。
- 黑雾单位：`owner_id === "dark_fog"`、`type === "dark_fog"`（ hostile to 所有玩家）。
- `is_moving` / `target_pos` 已删除；用 model.ts 的 `unitIsMoving(unit)` / `unitMoveDestination(unit)`。

### 命令
- `client.cmdMove(selector, position)`、`client.cmdAttack(selector, targetEntityId)`：selector 支持单个 id 或 id 数组（框选批量，服务端走 target.entity_ids）。
- `client.cmdUnitOrder(selector, order, {position?, targetEntityId?})`：order ∈ attack_move/patrol/guard/hold/follow/retreat/stop。
- move/attack 语义：普通单位只是"下达路径/目标"，由服务端 tick 结算推进与开火；执行体（玩家机甲，unit.mecha != null）保留瞬移与手动一击，不接受 unit_order。
- 事件 `entity_moved`：下单时携带 `path`/`move_speed`/`stance`；到达时 `arrived: true`；放弃时 `arrived: false` + reason。
- 事件 `damage_applied`：payload 含 attacker_id/attacker_type（unit/turret/combat_squad/enemy_force/fleet）、target_id/target_type（unit/building/enemy_force/combat_squad）、damage、target_hp、shield_absorbed/squad_count/squad_losses（小队时）。
- 事件 `entity_destroyed`：entity_type unit/building/combat_squad/enemy_force，含 killed_by/owner_id。
- 新事件 `enemy_wave_incoming`（黑雾袭击预警，E3）：payload `{ nest_id, from: Position, count, level, target_building_id?, target_pos?, target_owner? }` —— C3 的核心数据源（来袭方向=from→target_pos 的方向）。
- 小队 `combat_squads[]` 已有 position/move_speed/path/member_max_hp/count/hp。
- 建筑受击带 `shield_absorbed`/`shield_remaining`（行星护盾）。

## C1 RTS 操作（验收：框选、多选、右键情境指令、Ctrl+数字编队、双击选同类、攻击移动、集结点、快捷键体系）
现状（侦察）：
- `planet-map/store.ts`：`selected: SelectedEntity | null` 单选；`interactionMode` = inspect/build/move/attack（move/attack 只带单 unitId）。
- 点击链路：2D `PlanetMapPixi.handleClick`(634) / 3D `PlanetMapThree onPick` → `use-planet-interactions.ts` → `submitPlanetCommand`。攻击靠 `resolveAttackTargetAtTile`（必须正好点中敌人）。
- 右键目前只 `exitInteractionMode()`（PlanetMapPixi.tsx:663 / PlanetMapThree.tsx:141）。
- 无键盘体系（仅 Esc/+-/r 零星，参考 PlanetMapPixi.tsx:531 的输入框守卫模式）。
要做：
1. 选择模型扩展：store 增加多选（如 `selection: { unitIds: string[] }` 或并列 `selectedUnits: string[]`），框选（2D Pixi marquee + 3D 屏幕矩形投影，`PlanetThreeScene.project` 已有 tile→屏幕）。
2. 右键情境指令：inspect 模式下有己方单位被选中时，右键点地=cmdMove（批量）、点敌=cmdAttack（批量）；无选中保持现状（取消模式）。
3. 快捷键：A=attack_move（进入 attack_move 模式后点地，调 cmdUnitOrder attack_move）、S=stop、H=hold、P=patrol、G=guard、Ctrl+1..9 编队存 store、1..9 选编队、双击单位选同类同屏单位。输入框聚焦时忽略（沿用现有守卫）。
4. 双击选同类：同屏同 type 单位全选。
5. 集结点（生产建筑设置出厂集结点）——服务端尚无集结点字段，本项标记不做（列入 M2 U2），其余全部实现。
6. 多选面板：选中多个单位时显示数量与类型构成，可对全体下 move/attack/order。

## C2 3D 战斗表现（验收：弹道、爆炸、枪口火光、护盾受击、死亡与残骸、血条、炮塔转向）
现状（侦察）：
- 3D 场景 `planet-three-scene.ts`：完全不消费战斗事件（战斗总线只在 2D 订阅，PlanetMapPixi.tsx:324）。
- 2D 特效参考：`planet-effects.ts specsFromPlanetBattleEvent`（只消费 damage_applied：fire_flash/damage_float/hit_flash）。
- 炮塔模型 `three/industrial-models.ts turret()` 静态盒子+管子，无独立炮管。
- 单位无血条（2D 有 HP 弧 drawUnitDot 可参考）。
要做：
1. 3D 场景订阅 `engine/battle-events.ts`（subscribeBattleEvents），实现：开火弹道（attacker→target 的飞行光点/线段，按 attacker_type 配色）、命中闪光/伤害飘字（sprite）、爆炸（扩散球+粒子）、单位死亡（下沉/残骸短暂留存）。
2. 血条：3D 单位头顶 billboard 血条（hp/max_hp），受击闪白；黑雾单位红色标识（owner_id dark_fog）。
3. 炮塔转向：turret 模型拆出独立炮管 group，朝最近敌对目标方向旋转（目标来自 damage_applied 事件或最近敌人）。
4. 护盾受击：带行星护盾的建筑被命中时的波纹/闪光（shield_absorbed>0）。

## C3 局势感知（验收：受袭警报加一键跳转、小地图（敌我标记、告警闪烁）、来袭方向指示）
现状（侦察）：
- `event-toasts.ts:110` damage_applied 显式 return null 不弹 toast；无"基地遭受攻击"概念。
- 小地图 PlanetMinimap 只在 2D 渲染（PlanetPage.tsx:772 `!isThree &&`），工具条同(800)；3D 不写 mapProjection（Pixi 专有）。
- `model.ts extractAlertFromEvent` 已有告警雏形。
要做：
1. 受袭警报：己方建筑/单位被打（damage_applied 且 target 属己方）聚合告警（5s 合并窗口，"电厂 X 遭受攻击"），danger toast + 点击 requestFocus 跳转。enemy_wave_incoming → "侦测到黑雾袭击：N 单位来自 (x,y)，目标 (x,y)" danger toast + 跳转。
2. 来袭方向指示：屏幕边缘箭头指向 from 方向（2D 用 mapProjection，3D 需要把 from 方向投影到屏幕；简化：目标位置闪烁标记 + 小地图红线）。
3. 小地图 3D 可用：去掉 !isThree 限制；3D 下用相机朝向近似视口或只显示敌我标记层（建筑=绿点、单位=蓝点、黑雾=红点、来袭=闪烁红点）。PlanetMinimap 的 mapProjection 缺失时优雅降级（不画视口框）。
4. 工具条 3D 恢复显示（Zoom 相关在 3D 下无消费者的按钮禁用或隐藏）。
