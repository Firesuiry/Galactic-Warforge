# 工业发展与画质增强

2026-09-15。本轮以《戴森球计划》的工业建设与发展反馈为方向，完善现有生产、科研、物流与戴森玩法的玩家入口。它不是完整复刻，也不意味着原版全部内容或画质已经达到。

## 玩家入口

行星左上提供「生产规划」与「发展路线」；也可通过工作台的「生产」「发展」标签进入。3D 与平面战术共用这两套界面。

### 生产规划

- 产线诊断列出当前载入区域内己方生产/采集设施，区分暂停、缺电、未配置、加工中、下一批缺料与原料就绪；可仅看待检查设施。
- 原料缺口以建筑本地 inventory 与 input_buffer 为准，不把 output_buffer 当成可供投入的原料；加工中已经扣掉本批原料，不因此误报当前停机。
- 「定位并操作」选择真实建筑、移动镜头并打开详情；可继续使用已有装料、生产与物流操作。
- 配方支持按名称、ID、产物搜索；输入批次后列出原料、产出、副产物和基础单批时长。批次数用于规划用料，不会自动排产或凭空发放资源。
- 「建造」携带选中配方进入地图放置，最终以服务端建造结果为准。科技锁定时显示条件；资金、地形和执行体范围继续由现有建造流程检查。
- 配方产量属于基础配方估算，不是实时产率；当前区域设施不等于全行星资产统计。

### 发展路线

六个阶段串联现有玩法：

1. 落地与供电：风机、研究站、电磁学。
2. 自动化工厂：采矿、冶炼、制造、传送带与分拣器。
3. 矩阵与科研：启动矩阵加工周期、推进能量矩阵科技。
4. 行星物流：物流站与运输机。
5. 星际工业：星际物流科技、物流站和运输船。
6. 戴森能源：太阳帆发射、射线接收与恒星能源产出。

科技前置条件来自真实 catalog，已完成科技来自玩家状态。设施目标仅核对当前载入区域；移动镜头、拆除建筑或停止生产可能使对应目标重新提示。路线是实时检查清单，不是永久成就或额外奖励系统。物流与戴森数据只使用当前玩家、对应行星/恒星系的可用运行态。推荐动作直接进入建造或现有研究、物流、跨星球、戴森工作流。

## 画质

3D 行星视角控制中新增「画面质量」，无需重载场景即可切换，选择保存在浏览器本地。`?quality=low|balanced|high` 可以覆盖进入页面时的偏好，适合可复现验收。

| 档位 | 最大像素比 | 后处理抗锯齿 | 阴影 | 辉光 |
| --- | --- | --- | --- | --- |
| 流畅 | 1 | 关闭 MSAA | 1024 | 关闭 |
| 均衡（默认） | 桌面 1.75，窄屏 1.25 | 桌面 4×，窄屏 2× | 桌面 2048，窄屏 1024 | 开启 |
| 精细 | 2 | 4× | 4096 | 开启 |

实际 MSAA 采样不超过设备支持值，实际像素比不超过设备像素比。宽度小于 768px 使用窄屏预算。流畅档供低性能设备使用；软件 WebGL 的运行时间不能视为真实 GPU 帧率。

原本 renderer 的 antialias 设置未覆盖 composer 离屏渲染，现为离屏目标显式设置 MSAA。切换画质释放需重建的帧缓冲及阴影贴图，保留建筑、镜头与操作状态。

真实水域增加依据已探索相邻陆地计算的浅滩和泡沫；邻接遵守 cube_sphere 跨面规则。未知边界不会生成猜测海岸。大气的太阳方向与场景主光源统一。

## 验证方式

按 [3D表现开发指南](3D表现开发指南.md) 启动隔离测试服和 Web：

```sh
cd client-web
npm run build
npm test
SW_SKIP_WEBSERVER=1 npx playwright test tests/industrial-development.spec.ts tests/planet-three.spec.ts tests/system-three.spec.ts --workers=1
```

新增浏览器测试核对真实配方建造命令与服务端最终建筑，检查生产定位、发展动作、三档切换和 390px 操作。既有回归继续覆盖真实建造、单位移动、星球/恒星系切换与局势显示。海岸单测覆盖邻格、跨面和迷雾撤回；浏览器验证着色器编译与画面，不能仅凭单测声称完成水域视觉验收。

## 本轮验收结果

- 前端 70 个测试文件、515 项单测通过，生产构建通过。
- 6 项浏览器用例通过：5 项真实测试服操作（配方建造/发展导航/画质、390px 操作、建造与移动、恒星系往返、390px 恒星系），1 项显式戴森运行态 fixture 同步测试。
- 真实建造核对 POST 的 `recipe_id=electromagnetic_matrix` 与最终建筑配方；单位移动核对请求和服务端最终坐标。画质切换及桌面 3D 回归无页面/WebGL 错误。
- 390px 截图复核并修正视图切换与调试按钮重叠、标签挤压、生产/发展抽屉标题占用过多空间的问题。
- 软件 WebGL 下重新创建 3D 画布与 MSAA 截图较慢，画布等待为 30 秒，完整 3D 回归上限 300 秒；本次完整回归约 3.1 分钟。这是测试总时长，不是帧率指标。
- 当前真实测试服载入区域没有可观察的陆水交界，海岸邻接与迷雾边界通过单测验证；尚未完成真实大面积海岸的截图验收。
