# 星球玩法覆盖与验收

目标：完成《戴森球计划》星球内可建设设施及其玩法，包括玩家机甲。目录条目、模型、可建造标记、单元测试均不能单独证明整项玩法完成。以下是 2026-09-16 当前代码核查，后续迭代继续按全量目标验收。

## 当前已确认的缺口

- 当前 `mecha` 是可量产的地面战斗单位；`executor` 承担建造操作。尚不能将其视为完成玩家机甲系统。燃料仓、核心能量、个人制造、手动采集、建造无人机、飞行、充电、装备/护盾及升级实际效果仍须逐项实现和验证。
- `research.go` 中 `applyTechUnlocks` 的效果分支只有注释；驱动引擎等科技不能据目录声明认定生效。
- 自动集装机目前共用传送带缓存。`ConveyorState.MaxStack` 表示总物料容量，尚无独立货物层数/叠高吞吐模型，因此“真实集装增运”仍未完成。
- 截至本次核查，默认目录有 62 种建筑。每种均可建造，并不等于都有完整运行玩法。下列 16 种没有在 `defaultBuildingRuntimeDefinitions` 中单独声明，需继续核查是否由其他专用系统承担，再补缺口：四向分流器、流速监测器、物流配送器、行星物流站、星际物流站、制造台 Mk.II/Mk.III、分馏塔、微型粒子对撞机、地热电站、导弹塔、内爆加农炮、激光塔、等离子塔、信号塔、地基。

## 2026-09-16 精炼闭环

- 为 `oil_refinery` 补齐生产、6 能量/tick、电网连接、仓储和输入/主产物/副产物端口。
- 现有 `oil_fractionation` 改为精炼厂执行等离子精炼：2 原油 → 2 精炼油 + 1 氢。
- 新增 `xray_cracking`：1 精炼油 + 2 氢 → 3 氢 + 1 高能石墨。
- 新增 `reformed_refinement`：2 精炼油 + 1 氢 + 1 煤 → 3 精炼油。
- 三配方均为 60 tick/批，分别使用等离子精炼、X 射线裂解、重整精炼科技。
- 同时作为输入和输出的物料分离存放：原料保持在库存/输入缓存；完成后的产物进入输出缓存。必须经外部回流或玩家补料开启下一批，不能在完成前直接被输出口抽走。输出缓存满时整批等待，不部分发货或丢失副产物。
- 回归：`server/internal/gamecore/refinery_test.go`；浏览器回放：`scripts/playtest-refinery.mjs`，需隔离 war-map 测试服解锁三种精炼科技并提供脚本头部列出的原料。可设置 `SW_REFINERY_WEB` 与 `SW_REFINERY_EVIDENCE`。

本轮已实测：隔离服 `19486`，Web `4176`；通过浏览器生产规划选择配方并建造三台精炼厂、补建三台风机、API 装料后读取真实产出。结果分别为 2 油+1 氢、3 氢+1 石墨、3 油，无浏览器错误。证据 `/tmp/sw-refinery-review/browser-results.json` 和 `/tmp/sw-refinery-review/refinery-browser.png`（临时文件可通过回放脚本重新生成）。此证据覆盖配置了科技和原料的测试场景，不能替代普通新局全科技推进验收。
