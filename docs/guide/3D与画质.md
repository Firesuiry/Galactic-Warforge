# 3D 与画质

目标：《戴森球计划》式星球工业观感（近景机械细节、自然地表、运行动画、光照、清晰操作）。服务端负责生产、物流、战斗、资源与权威坐标；前端只表现已收到的状态，不增添虚假的建筑、运输任务或情报。

> 2D「平面战术」行星视图已在第 20 轮（2026-10-18）删除，行星页只有 3D；星图与战场仍用 Pixi。

## 1. 立方体球面网格（服务端与前端共用协议）

行星只有 `cube_sphere` 一种拓扑，配置 `planet.face_size: N`（默认 `map.yaml` 为 816，约 400 万格）。服务端保存六个 N×N 面，二维存储图集为 3N×2N；`map_width` / `map_height` 只是图集尺寸，不是经纬度或平面边界。旧 `planet.width/height` 配置与不含球面拓扑的旧存档直接拒绝加载。

面序号 `face = floor(y/N)*3 + floor(x/N)`，面内坐标 `(x%N, y%N)`：

| face | 法线 | 向右 U | 向下 V |
| --- | --- | --- | --- |
| 0 | +Z | +X | -Y |
| 1 | +X | -Z | -Y |
| 2 | -Z | -X | -Y |
| 3 | -X | +Z | -Y |
| 4 | +Y | +X | +Z |
| 5 | -Y | +X | -Z |

- 权威实现：`server/internal/surface/grid.go`（`frames`、`Step`、`Normal`、`FromVector`）；前端镜像 `shared-client/src/surface.ts`。两端用 `server/internal/surface/cmd/fixtures` 生成的 `shared-client/src/surface-fixtures.json` 做跨语言几何/方向样例对拍。
- 等角投影：面内 u/v 映射到 [-π/4, π/4]，方向 = normalize(N + tan(u)·U + tan(v)·V)。两极位于完整面内部，无经纬汇聚；边角仍有受控形变，不保证所有格子完全等大。
- `FromVector` 主轴并列时依次优先 Z、X、Y，浏览器与地形着色器一致。
- 邻接只由球面四邻接图决定（`Step` 为纯整数图运算）：图集相邻像素不一定是地表邻居，图集外边缘也不是世界边界。客户端禁止对 x/y 取模、夹紧或直接加减代替邻接。范围、寻路、视野、资源团簇、出生区都用服务端球面图。
- 方向：每格有 north/east/south/west 面内方向，跨边后方向随面旋转；传送带出口、分拣器、建筑端口、仓储/电网连接使用同一套方向运输规则。
- 多格建筑按锚点面内偏移运输到相邻面，占据、施工预留、完成、拆除、摧毁、存档恢复都处理全部占地。宽高不得大于面宽；绕立方体角点导致自重叠时拒绝放置。
- 建筑布局蓝图的矩形选区、旋转与粘贴限于单面（跨接缝结构分面建蓝图）；单体建筑、物流、单位可跨面。与战争单位蓝图无关。

### scene 查询与补片

- 状态、行星查询、快照都带 `surface: {topology: "cube_sphere", face_size: N}`。
- `GET /world/planets/{id}/scene` 的 `x/y/width/height` 是图集矩形裁剪；可同时传 `near_x`、`near_y`、`radius`（0..128）获取按球面图距离计算的邻域 `surface_patches`。每片有独立 `bounds/terrain/visible/explored`；主 `buildings/units/resources` 合并补片实体并去重。绘制须按每片 bounds 读坐标与迷雾，未探索补片为 unknown，不得从相邻图集像素推测地表。
- CLI：`scene planet-1-1 0 0 32 32 --near_x 0 --near_y 16 --radius 16`。
- 建造前自动靠近：请求 `/world/planets/{id}/path`，以执行体 `operate_range` 作 `stop_range`，按返回 waypoints 移动；范围内返回空 waypoints；不可达/未知目标不得继续自动建造，每段移动后处理权威失败回执。

## 2. 3D 场景实现

- 操作：行星与恒星系页均为 3D；拖动旋转、滚轮/按钮缩放、俯仰滑条；全球视角拉远、聚焦基地返回近景；点建筑/单位看详情，建造栏选建筑后点地表放置，选中单位后点地表移动；Esc/右键取消指令模式。
- 代码：`client-web/src/features/planet-map/planet-three-scene.ts`（场景、镜头、输入、快照同步）；`three/` 拆为投影（`projection.ts`）、地表（`local-surface.ts`、`terrain.ts`、`surface-dressing.ts`）、工业资产（`industrial-models.ts`、`industrial-finishes.ts`）、合批（`static-batches.ts`、`dynamic-batches.ts`）、运行表现（`industrial-activity.ts`、`conveyor-geometry.ts`、`sorter-animation.ts`、`logistics-flight.ts`、`combat-effects.ts`）、画质（`render-quality.ts`）、空间与大气（`space.ts`、`atmosphere.ts`、`atmospheric-fog.ts`）、后处理（`post/grade-pass.ts`、`post/sun-flare.ts`）、镜头手感（`camera-motion.ts`）；恒星系为 `system-three/`。
- 光照与大气（第 23 轮 3A）：物理天空穹顶（单次散射近似，天顶深青蓝 → 地平线雾霾白、太阳圆盘与眩光、按大气浓度衰减的星点）按相机高度在天空与太空之间过渡（≤25 全天空、≥60 纯太空）；环境光用「只含天空的 PMREM」做 IBL（换星球/换档位时重建，不逐帧），不再用室内灯箱。**IBL 的烘焙相机放在相机当前所在的地表点**（`skyIblObserver`，不能放球心：放球心时天空 shader 的地平线判据处处 90°，地平线白完全丢失 → 陶瓷白偏冷），天空色在烘焙时去饱和并把 G 压到 0.64（去青、阴影不发青绿）。全球视角另有一层散射壳（半径 1.025R，日面瑞利蓝、明暗交界偏橙、夜面不纯黑）；中空（高度 ≥60，相机已在壳外）同样显示，壳的边缘落在地平线弧上形成一条细亮蓝色光带。空气透视雾用自定义 fog chunk：**雾色是线性 HDR 色**（目标显示色 #b9d3e6 的 ACES 反解值，世界渲染进 HalfFloat RT 时 fog 在线性空间执行），取视线方向的地平线色 + 朝太阳内散射，浓度按距离平方与相机高度变化（贴地中心建筑 < 5%、地平线约 60%；中空按 1/√高度 变淡），地表、建筑、单位都吃雾，天空、additive 特效与自定义 ShaderMaterial 不吃。
- 后处理链：RenderPass → GTAO（low 关 / balanced 半分辨率 / high 全分辨率；**每帧把深度重绑到 `composer.readBuffer.depthTexture`**，两块 RT 的深度纹理是克隆，绑死其中一块会读到全 0 让 AO 全灭）→ UnrealBloom（strength .38、radius .42、阈值 1.2，只让发光件泛光）→ OutputPass（ACES + sRGB）→ 调色（lift/gamma/gain、饱和 1.05、对比 1.06、高光暖暗部冷的分离色调、暗角 .18、颗粒 .015）→ SMAA。composer 离屏目标不开 MSAA（GTAO 需要可解析的深度，抗锯齿交给链末的 SMAA）。阴影用 PCF（r186 已移除 PCFSoft），软硬按档位调 `shadow.radius`，阴影视锥边缘 15% 在 shader 里渐隐、不出现硬切线；视锥范围随相机高度与俯仰放大。
- 镜头手感：只有用户输入路径有阻尼——拖拽松手后约 300ms 惯性衰减，滚轮/缩放按钮 180ms 缓动，回家/全球视角 600ms ease-in-out；测试钩子（`focus/zoom/setAltitude/orbit/rotateView`）与深链、夹具仍立即生效，`?freeze=1` 与 reduced-motion 下一律立即。
- 代码：`client-web/src/features/planet-map/planet-three-scene.ts`（场景、镜头、输入、快照同步）；`three/` 拆为投影（`projection.ts`）、地表（`local-surface.ts`、`terrain.ts`、`surface-dressing.ts`）、工业资产（`industrial-models.ts`、`industrial-finishes.ts`）、合批（`static-batches.ts`、`dynamic-batches.ts`）、运行表现（`industrial-activity.ts`、`conveyor-geometry.ts`、`sorter-animation.ts`、`logistics-flight.ts`、`combat-effects.ts`）、画质（`render-quality.ts`）与空间（`space.ts`）；恒星系为 `system-three/`。
- 地表：全球是一张 `SphereGeometry(100,192,128)`；每格烘焙五张 RGBA8 属性图（全局 overview + 场景窗口 local，通道语义相同）：`color` 宏观色、`properties`（R 水 / G 岩性占比 / B 已探索 / A 可见）、`coast` 四向海岸、`heat`（R 岩浆距离 / G 水距离 / B 服务端 height / A 到未知区距离）、`sdf`（每格 8×8 超采样、线性过滤的平滑类别场：R 水面 / G 岩性 / B 岩浆 / A 到未知区，0 为等值线）。**亚格边界**：三类类别都用 `sdf` 的 0 等值线分类（宽核均值把格边磨圆，再叠格尺度噪声弯折），所以水/陆、阻挡/可建造、岩浆/可建造的边界是连续曲线而不是方块阶梯；离岸距离也直接取该场，浅滩/泡沫/沙泥与同一条岸线对齐。未知格恒为「外侧」，等值线停在探索前沿。未探索格的 terrain/height 从不写入图集，着色器也不读隐藏格的地形色。点击、选中圈、建筑姿态与尺寸用同一球面映射（RADIUS=100，不做几何位移）。
- 地表 PBR（第 23 轮 3A 画质地表分支，`three/terrain/*`）：11 层 1024² ambientCG CC0 纹理打进两张 `sampler2DArray`（albedo sRGB + packed：法线 xy / 粗糙度 / 高度）。球面**对象空间三平面**采样，立方体面接缝处天然连续；一次重复约 3 格，再叠一层宏观尺度与一层旋转相位的中尺度调制打散平铺感；像素覆盖大时淡出到宏观色（全球视角无摩尔纹）。群落：buildable = 苔草/火山土/碎石按世界坐标大尺度噪声 + 纹理高度混合；blocked = 玄武岩 + 地衣岩；临水一圈沙泥、临岩浆一圈焦土（距离场来自已探索邻格）；ice 星球换雪/蓝冰/裸岩；不同星球按 ID 种子微调色相/饱和/明度；服务端 `height` 只改颜色与潮湿度，不抬升几何。远景降级与 `?quality=` 无关（按像素覆盖自动）。
- 水：深青 `#0d3a46` 系，按离岸距离由浅到深；两层滚动法线（球面 UV，按纬度补偿极点挤压）+ 菲涅尔天空反射 + 太阳高光；泡沫只在已探索陆/水相邻处出现（跨面邻接规则不变）。
- 岩浆：噪声板块硬壳（玄武岩近黑）+ 网状裂缝 + 裂缝里的熔体自发光（`#ff5a1f` 量级，bloom 吃到），缓慢流动，冻结时固定相位。
- 植被与岩石（`three/surface-dressing.ts`）：只在已探索格、排除实体占地（建筑/单位/资源点），实体变化时整组重建；禁用 raycast。不可建造岩地的岩脊（`local-surface.ts`）用**连续岩性掩码**（格心双线性 × 占地清零）抬升：相邻阻挡格连成一片缓丘，边界一格拉回数学球面，不再逐格一块灰色台地。草丛为程序化五叶簇 + 顶点风摆（冻结静止）；岩石用 Poly Haven CC0 扫描网格（3 种，≤1.8k 三角，见 `public/assets/models/rocks/THIRD_PARTY.md`，异步加载，未就绪时程序化碎石回退）；可建造地零星卵石，ice 星球改扁平碎冰。实例预算按档位 low 4k / balanced 15k / high 40k（`DRESSING_BUDGET`），相机高度 ≥190 整组隐藏。不可建造岩地的局部岩脊仍由 `local-surface.ts` 生成（排除实体占地）。
- 矿脉（`three/ore-deposits.ts`，从 `industrial-models.resource()` 迁出）：按资源 kind 分造型与材质——铁/铜/煤/石/钛为**扫描岩石矿座**（Poly Haven CC0 网格 3 块拼合，金属类表面撒闪点，材质取岩石 albedo 的中性化细节图），硅/稀有矿为半透明晶簇（稀有矿颜色走 `itemColor()`），原油/水/硫酸为液池（原油虹彩、酸液微光），原木为树、植物燃料为灌木；同 kind 共享几何/材质与 3 个位置变体；建筑占地内的露头压低为地表矿层，枯竭矿去掉晶簇/液面并压暗压扁。扫描岩石异步加载，就绪后丢弃矿点几何/材质缓存并重建。
- 云层（`three/clouds.ts`）：半径 101.2 的云壳（大气壳 ≈102.5 在外），fbm 云缓慢旋转；覆盖率只由世界坐标噪声决定，与探索/迷雾无关（不泄露信息）；相机高度 <30 全透明、>90 满显；冻结/reduced-motion 固定相位；禁用 raycast。
- 未探索区：深石板测绘面纱 + 细测绘网格 + 等高线式程序纹理（与真实地形无关，远处淡出防摩尔纹）+ 细而淡的青色前沿光；已探索区边缘的柔和过渡**只在已探索格内部**生效，未探索格永不显示地形色。
- 合批：工业资产共享模板几何/材质；`StaticBatches` 按图层/几何/材质跨建筑实例化静态部分，`DynamicBatches` 独立合批转子、钻头等动画子树，只更新变化的姿态；生产状态变化与世界旋转不重建静态实例。实例射线拾取映射真实建筑地块。
- VFX（3A 画质 vfx 分支，`three/vfx/`）：GPU 粒子（顶点着色器按 `t − 发射时刻` 解析运动，CPU 只写一次缓冲；additive/alpha 各 1 个绘制调用，环形缓冲按档位 900/2600/5000 上限）、战斗演出（枪口焰 + 曳光 + 命中火花 + 焦痕 + 冲击波 + 点光源池 ≤ 4 + 火球/烟/碎片分层 + 残骸冒烟 + 护盾菲涅尔气泡）、工业氛围（`collectActivity` 的 heat/energy/mining/**process** 源 → 熔炉火光火花烟、火电烟柱、化工炼油蒸汽、采矿扬尘、装配台焊花、研究站光粒；设备暂停/缺电/矿点枯竭即无源、不发射）、施工全息（目标模型 + 菲涅尔/扫描线，按进度自下而上溶解）、选中反馈（建筑四角括号 + 地面光晕、单位细环 + 方向三角）、补给光环与射程圈（≤ .06 格虚线环 + 极淡径向渐变，运行/停机语义不变）、镜头震动（爆炸按距离与规模，`add/apply/restore` 只在 `composer.render()` 前后各一行）。粒子贴图 `public/assets/vfx/particles.png` 由 `scripts/gen-vfx-atlas.mjs` 离线生成（无第三方素材）。`?freeze=1` / reduced-motion 下所有特效停在固定相位、战斗事件不演出（画面是时间的纯函数）。

  - 活动源口径（信息诚实）：`heat` = 熔炉/高炉 `production.remaining_ticks > 0`；`process` = 其余生产建筑（制造台/化工/炼油）配方在跑，或**研究模式**（未设配方、服务端 `isResearchLab` 同口径）且 `state=running` 的研究站；`energy` = 有发电输出，`mining` = 有采集且矿点仍有效。表现按**建筑类型**分流（`EMITTER_OFFSETS` 里登记的类型才发）：`/smelt|furnace/` 火光 + 火花 + 轻烟、`/assembling_machine|recomposing_assembler/` 焊花、`/chemical_plant|oil_refinery/` 蒸汽、`/matrix_lab|research_station|self_evolution_lab/` 光粒；未登记的类型（仓储、防御、物流）不发射。
- 运行表现：`IndustrialActivity` 由真实传送带 buffer、运行状态、生产剩余 tick、物流位移生成货物、火花、热气与尾迹，暂停设备停止机械动画；矿点枯竭不播采矿火花。连续传送带合并为一条运输链（整网约 3 个绘制批次），按服务端 `runtime.params.io_ports` 连接矿机、熔炉、仓库、物流站端口。分拣器仅在 `runtime.state=running` 且收到新 `last_transfer` 时播放机械臂；记录上次观察 tick，慢刷新时两次快照间的新搬运也播放一次，陈旧/重复/未来记录不播放；当前搬运完成后才切换下一条路线。建筑占地内的矿石露头压低为地表矿层（仅表现）。
- VFX 运行表现（`three/vfx/`，档位表 `VFX_QUALITY`：low/balanced/high → 粒子上限 900/2600/5000、发射率 0.45/0.8/1、动态光源 0/2/4、焦痕池 12/24/32；切档时场景**重建 VFX 层**并恢复活动源，上限立即生效）：粒子每批（additive/alpha）各 1 次绘制调用，全部存活粒子共用一次缓冲上传，CPU 每帧只推进一个时钟；工业发射器按建筑类型查发射口表（`EMITTER_OFFSETS`，高度按占地缩放），同一相位窗只发一轮，冻结时按固定相位预发射 `PRIME_ROUNDS` 轮后不再新增；战斗演出上限 曳光 48 / 焦痕 按档位 12–32 / 冲击波 16 / 点光源 4 / 碎块 96 / 护盾 12 / 残骸 10 / 伤害飘字 24，池满顶掉最旧、不增长内存；爆炸分层 = 火球（additive 序列帧）+ 深灰烟（alpha，`delay` 接在火球之后）+ 暗色碎块（解析抛物线，落地淡出）+ 细冲击波（半径 1.5 格小 / 3 格大，环宽 ≤ .12 格，0.35s 淡出；暖白 `#ffc98a` × 线性增益 2.8 越过 bloom 阈值，读成亮橙白而不是米色）+ 焦痕（8s 淡出）+ 残骸冒烟（击毁后 4.2s 内每 0.45s 一批）+ 护盾菲涅尔气泡（只在服务端 `shield_absorbed > 0` 时）；曳光宽 0.2 格，相机高度 > 20 时按像素下限保持 ≥ 1.5px 不再加宽；选中建筑的四角括号中心 = 占地中心（`footprintCenterTile`）、尺寸 = 占地 ×.9，收拢动画与 `VfxLayer.currentTime` 同一时钟；施工全息克隆整棵目标模型树（保留根 scale，尺寸 = 实物），溶解高度按该模型局部包围盒写 `uHeight`，additive 混合避免大块合并几何糊成实心青板；工业粒子速度单位是**格/秒**，只在 `ParticleSystem.emit` 里乘一次格宽；`gl_PointSize` 换算乘 `devicePixelRatio`；`?freeze=1` / reduced-motion 下战斗事件不演出、粒子停在固定相位（画面是时间的纯函数）。视觉夹具帧率（本机解除 vsync，`node scripts/fixture-shots.mjs <目录> --port <自己的端口> --fps`；第三轮并入 3A 光照后复测，Explosion/TurretFire/Construction/Industry/Selection 依次 271/260/266/255/252 fps，绘制调用 192/318/208/176/298）；balanced 档 Explosion 553 / Industry 566 / Showcase industry-overview 512 / horizon 521 fps（并入光照前口径）。绘制调用（high，Showcase 固定机位，并入光照前复测）：industry-overview 296（367 fps）、assembling-machine 143（504 fps）、horizon 287（508 fps），相对修前 294/141/285 各 +2 次（两个粒子批）。

## 5. 素材

- 工业建筑、车辆、飞船、矿簇的模型来自两处：`three/industrial-models.ts` 原创程序化建模（金属/陶瓷/玻璃/发光共享材质）与 `three/industrial-gltf.ts` 的现成 GLB（Kenney CC0，见 `client-web/public/assets/models/THIRD_PARTY.md`）。不引用《戴森球计划》模型或贴图。
- 现成 GLB 只覆盖原来走通用兜底 `factory()` 的 19 个建筑与 6 类单位/飞船；有专属程序化模型的建筑（研究站、矿机、熔炉、带子、分拣器、炮塔、发电、仓储、物流站等）与机甲/车辆仍用程序化模型。映射表在 `industrial-gltf.ts` 的 `BUILDING_GLTF` / `UNIT_GLTF`，键是服务端类型，不新增服务端不存在的实体。
- 加载是异步的：场景构造后 `IndustrialModels.preload()` 加载一次，完成后 `reloadTemplates()` + 重建实体；期间 `building()` / `unit()` 仍同步返回程序化模型，不出现空建筑。模板按阵营各克隆一份材质（不污染共享材质），实例间继续共享几何/材质，`StaticBatches` 照常合批。
- 同机位前后对照：`scripts/playtest-shots/cp-army.mjs`（`--procedural` 强制程序化回退），逐模型画廊 `node develop_tools/three_assets/gallery.mjs <目录> --units`。
- 地表纹理：`client-web/public/assets/textures/terrain/`（ambientCG CC0，1K → 1024² webp，共 12.4 MB），每层 `*_albedo.webp`（sRGB）+ `*_packed.webp`（R/G 法线 xy、B 粗糙度、A 高度），另有 `lava_emissive.webp` 与 `water_normal.webp`（512²）。来源、作者、许可与改动见该目录 `THIRD_PARTY.md`；纹理总量预算 20 MB（地表）。**调色**：加载时按层把 albedo 的线性平均色校正到 `texture-library.ts` 的 `LAYER_TARGET`（苔草橄榄 `#5d6b3a` 系、火山土暖褐灰、玄武岩冷调），像素按 `目标色 × (像素/均值)^0.8` 重算——ambientCG 原图各自偏色（火山土平均色是暖黄），不校正整块地表会读成黄绿。第 23 轮第三轮（L19）把全部目标色整体提亮一档：火山土真机渲染后 sRGB 亮度 ≥ 50/255（不再接近纯黑），士兵（深色单位）与周围地面的亮度差保持在 40 以上；cp-army overview 全图平均亮度 71 → 93。
- 扫描岩石：`client-web/public/assets/models/rocks/`（Poly Haven CC0：rock_09 / rock_07 / moon_rock_01，减面到 ≤1.8k 三角，归一化到底面 y=0），自定义紧凑 `.bin`（uint32 头长 + JSON 头 + 索引 + pos3/normal3/uv2），解析见 `three/terrain/rock-meshes.ts`。
- 表面细节由 `three/industrial-finishes.ts` 运行时确定性生成 9 张 256×256 纹理（陶瓷接缝与紧固点、拉丝合金、格栅；颜色 sRGB、粗糙度/法线线性，启用 mipmap），无外部下载。
- 表面材质：主族（陶瓷白涂装、拉丝钛、石墨钢板、花纹板、橡胶、哑光塑料）用 `client-web/public/assets/textures/materials/` 的 ambientCG CC0 1K webp（albedo + 打包 ORM + NormalGL，合计约 2.7 MB，来源与改动见该目录 `THIRD_PARTY.md`），由 `three/industrial-materials.ts` 异步预加载，**三平面映射**（`onBeforeCompile` 按对象空间坐标采样，不依赖几何 UV；重复密度按**格**算——`uTriScale = repeat / tileScale`，场景在 `setData` 里按当前 `face_size` 更新 uniform，所以 face 288 与 816 的大面/小零件密度一致）；阵营色由调色板（`three/palette.ts`）经着色器 `uTriTint`（目标色 / albedo 均值）乘上去，贴图本身保持中性。加载完成前、或单套贴图加载失败时回退 `three/industrial-finishes.ts` 的运行时程序纹理（陶瓷接缝、拉丝合金、格栅），不出现黑/粉材质。`?procedural-textures` 可强制回退做对照。
- 调色板 `three/palette.ts` 集中阵营色（己方陶瓷白/石墨/钛、敌方枪灰、黑雾黑曜石）、发光色（青/锈橙/品红/警示琥珀）与粗糙/金属参数；程序化模型、GLB 阵营涂装（`industrial-gltf.ts` 只改取色来源）、状态灯、传送带/分拣器材质都从这里取色。
- 状态灯 `three/status-lights.ts`：每栋己方建筑一个指示灯，全场 1 个灯珠 InstancedMesh + 1 个光晕 InstancedMesh；运行青、空闲/缺料琥珀、缺电红（1.6s 慢闪，冻结定格）。状态只取权威 `runtime.state`，切换只写 `instanceColor`，不重建静态批。灯位按建筑**顶面包围盒** + 类型偏移算，实例矩阵写在建筑图层空间（`inverse(layer.matrixWorld) × root.matrixWorld`），世界旋转/聚焦不漂移。
- 运行发光件按 2.2 rad/s 缓慢呼吸（共享材质只写一次）；**停机建筑的发光件逐栋降到 30%**：发光材质注入 `totalEmissiveRadiance *= vColor.rgb`，`StaticBatches` 把停机建筑的发光件单独拆一批、实例色写 0.3 灰，不动共享材质。冻结时呼吸定格在最亮相位。
- 传送带 / 分拣器的金属件与带面同样走 PBR：构造时贴图可能未就绪，先给纯色，贴图加载完成后 `upgradeMaterials()` 原地换材质并重建网格（带面橡胶法线是克隆副本，改 repeat 不污染共享贴图）。
- 程序化建筑的三角面预算：每栋 ≤ 6k（薄件用 12 三角直角盒、圆环 4×20 段、穹顶 16×8 段；单测 `industrial-models.test.ts` 覆盖）。
- 建造栏缩略图 `client-web/public/assets/buildings/*.png`：同一模型的 256×256 透明渲染，覆盖全部建筑类型。重建：先起 Vite（默认 4173），运行 `node develop_tools/three_assets/render.mjs [vite地址]`，联系表输出 `/tmp/industrial-assets.png`。
- Kenney Space Kit / City Kit (Industrial)（均 CC0）的 GLB 子集在 `client-web/public/assets/models/`，只提交映射表引用的文件；许可与来源见该目录的 `THIRD_PARTY.md`。
- Orbitron 字体随客户端本地提供（`client-web/public/fonts/orbitron/`），不依赖 Google 字体 CDN。
