# 3D 素材来源

本版星球场景使用 Three.js 渲染。生产、资源、战斗和实体状态仍以服务端为准；模型仅用于已有建筑与单位的外观表现。

- 原始许可随素材保存在 `client-web/public/assets/space/License.txt`。
- 仅提取少量 GLB，保留原始文件名和内容；不引入整包素材。模型内置材质，无外部纹理或解码器依赖，运行时由本站提供，不依赖第三方 CDN。

模型使用 Y 轴向上、底部约为 Y=0 的坐标系，原始尺寸不统一；场景加载后按包围盒归一化。星球、大气、地块、选中标记及轨道等视觉元素由代码生成。
