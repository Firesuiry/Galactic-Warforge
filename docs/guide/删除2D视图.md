# 第 20 轮：删除行星页 2D「平面战术」视图（契约）

2026-10-18 用户确认：行星页只保留 3D（`PlanetMapThree`）。理由：3D 是默认视图、2D 不是 WebGL 回退；每个画面功能做两遍；高架/立交在 2D 里只能凑；DSP 本身没有 2D 建造图。
摸底依据：第 19 轮只读摸底（PlanetMapPixi 与 PlanetMapThree 逐项对比、共用代码、依赖用例），结论见本页「摸底要点」。

## 1. 已拍板的决定

| # | 问题 | 决定 |
|---|---|---|
| D1 | 3D 是否重建 DOM 实体层（`data-entity-*`） | **不重建**。逐帧把实体投影成 DOM 有性能代价。E2E 一律用 `window.__planetThree`（`VITE_E2E=1` / dev 暴露）的投影与查询接口；`planet-entity-dom.spec.ts` 删除。 |
| D2 | 战区划定（theater_zone / `onDefineZone`） | **3D 里做拖拽**：工具条「划定战区」进入模式 → 左键在球面拖出矩形（与 Shift 框选同一套投影判定）→ 松开调用 `onDefineZone`；`PlanetTheaterControls` 在 3D 下显示；Esc / 右键退出模式。 |
| D3 | 3D 截图基线 | `?freeze=1&quality=low` + 固定 DPR 1 + 固定窗口 + `maxDiffPixelRatio` 容差（与 [视觉夹具](视觉夹具.md) 同口径）。 |
| D4 | 可选补项 | **做**：建造 ghost 射程圈（`combat_range` / `power_range`，含供电覆盖）、选中防御建筑的射程圈、侦测点（detections）、施工进度（脚手架上方进度条）。**不做**（以后再议）：主图来袭方向线（小地图已有）、管道节点、小地图视口框。 |
| D5 | 小项 | +/- 键缩放 3D；Esc 同时清空小队选择；图层面板去掉缩放档按钮；`layers.fog` 开关控制 3D 测绘面纱、`layers.terrain` 开关删除；调试面板分享链接/视口 JSON 改为 3D 中心格 + zoom + tilt。 |
