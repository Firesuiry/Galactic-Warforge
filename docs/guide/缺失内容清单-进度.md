## F4 侦察笔记（2026-09-29，供 F4 实施用）

- 结算侧已基本就位：planetary_runtime/interstellar_runtime 已遍历全部已加载世界（战斗/黑雾/物流/胜负判定 F3 全世界扫描）。例外：`settleWarIndustry` 只结算 currentWorld；`settleDistributors(..., ws.PlanetID == gc.activePlanetID)` 只在活动行星派发。
- 玩家状态是全行星共享的（`buildSharedPlayers` 一份 map 挂到每个 world），所以 F4 不用搬玩家经济，只需给命令选对世界。
- 命令路由缺口：`executeRequest`（core.go:679）把 `gc.world`（全局活动行星）传给所有 exec*。deploy_squad/planet_commands 已有 `WorldForPlanet(payload.planet_id)` 自行改路由的先例——F4 应把目标行星路由做成统一约定（每个 exec 开头按 payload 的 planet_id 或实体 ID 反查世界；实体→行星可用注册表索引或遍历 worlds 做 map 查找，行星数小，O(N·1) 可接受）。
- 机甲与活动行星耦合：`player.SyncLegacyExecutor(activePlanetID)`（runtime_registry.go）意味着机甲只活在全局活动行星；F4"每人独立焦点"= 机甲位置即该玩家的焦点，命令按机甲所在世界路由，`switch_active_planet` 退化为客户端视图焦点。
- 已有 VictoryRule 配置：`elimination|mission_complete`（model/victory.go，NormalizeVictoryRule 折叠未知值）——F1 的 victory_mode 直接暴露它即可。
