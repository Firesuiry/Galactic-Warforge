# 3A 画质（第 23 轮）

目标：行星 3D 画面从「玩具原型」提升到电影感的硬科幻星球工业（参照《戴森球计划》的星球工业观感、《Satisfactory》的 PBR 与植被密度、《Homeworld》的军事单位质感）。
修前基线：`tmp/3a/before/`（真机 cp-army 固定机位）、`tmp/3a/before-fixture/`（展示夹具）。

## 1. 美术方向（所有分支共同遵守）

| 项 | 规定 |
| --- | --- |
| 基调 | 干净但有使用痕迹的硬科幻；对比靠光影与 AO，不靠压黑；饱和度克制，发光件是视觉焦点 |
| 太阳 | 暖白 `#ffe2bd`，日光感（不是黄昏橙）；方向保持现有（左上前方，太阳相对相机固定） |
| 天光/补光 | 冷蓝 `#9cc7ff`；暗部可读（不得出现纯黑死角） |
| 己方 | 陶瓷白 `#e9edf0`（粗糙 .45）+ 石墨 `#2a3036`（粗糙 .6 / 金属 .3）+ 拉丝钛 `#9aa3ab`（金属 .9 / 粗糙 .35）；发光青 `#3fe6ff`；警示琥珀 `#ffb04a` 只点缀 |
| 敌方玩家 | 枪灰 `#3b3f45` + 锈橙发光 `#e0662a` |
| 黑雾 | 黑曜石 `#120c16` + 品红发光 `#ff2a6a`，带虹彩 |
| 地表（rocky，含岩浆，如 planet-1-1） | 「温带火山」：可建造地 = 苔草 `#5d6b3a` / 火山土 `#3a332d` / 碎石三者按大尺度噪声混合；阻挡格 = 玄武岩露头 `#2b2a2c` 带地衣；岩浆 = 橙红自发光 + 冷却硬壳；水 = 深青 `#0d3a46`，菲涅尔反射天空 |
| 地表（ice） | 雪 / 蓝冰 / 裸岩；其它 kind 按种子在同一套材质上偏色，不同星球一眼可分 |
| 天空 | 贴地：大气散射天空（深青蓝天顶、地平线发白的雾霾、太阳圆盘与眩光），天顶隐约可见星；升到中空（高度约 40 以上）渐变为太空 |
| 太空看星球 | 瑞利蓝的大气边缘 + 薄云层 + 明暗交界与夜面 |
| 后处理 | ACES Filmic + 调色（lift/gamma/gain、饱和、暗角、极轻胶片颗粒）+ GTAO + 只让发光件泛光的 Bloom + 太阳镜头光晕 |

## 2. 硬约束（违反即返工）

1. **信息诚实**：未探索区永远是未知（不画真实或猜测地形）；特效、状态灯只由真实运行状态 / 事件驱动；不为截图虚构地形（夹具里的合成地形只用于迭代，不能当验收图）。
2. **拾取与放置**：数学球面 `RADIUS=100` 不变；可建造格不做几何位移；实体贴球面；`userData.tile`、批次 `resolveHit` 的拾取路径不变。
3. **冻结确定性**：所有新动画/噪声/粒子遵守 `?freeze=1` 与 reduced-motion；冻结后画面是时间的纯函数（固定相位、固定随机种子）；GTAO/颗粒等带噪声的效果在冻结下也必须逐帧一致。
4. **节点名契约**：`turret-barrel`、`logistics-bot-cargo`、`transport-robot-cargo`、`userData.industrialRotation`、`userData.industryActive`、`independentMaterial` 保持语义。
5. **合批**：同类实例共享几何与材质对象；同一合并组内属性集一致（现为 position/normal/uv；要加 uv2/tangent/color 必须整组一致）；不逐实例克隆材质。
6. **测试钩子**：`window.__planetThree` 的现有方法签名不变（可新增）；`PlanetMapThree.test.tsx` 的 mock 同步更新。
7. **画质档位**：`render-quality.ts` 归光照分支所有；其它分支不改它，各模块自带「档位名 → 参数」表，入参用 `'low' | 'balanced' | 'high'`（场景 `getQuality()`）。low 档也要好看，只砍开销大的项。
8. **后处理 pass 只归光照分支**：别的分支不往 composer 加 pass（选中描边等用网格方案）。
9. **素材许可**：CC0 / CC-BY / CC-BY-SA（NC 仅在没有替代时用，并标注）；不用商业游戏提取的素材（仓库公开 + 视频投稿）。每个素材目录有 `THIRD_PARTY.md`（来源 URL、作者、许可、改动）；CC-BY 必须署名。
10. **体积预算**：纹理（地表 + 材质）≤ 40 MB，模型 ≤ 60 MB，音频 ≤ 20 MB；纹理用 webp（1K 为主，近景主材质最多 2K）。

## 5. 验收

- 每个分支：夹具修前修后同机位成对截图（`fixture-shots.mjs`，high 档）+ 帧率数字；最后起一次真机（`playtest-up.sh <N> --checkpoint cp-army` + `playtest-shots/run.mjs <N> cp-army <目录>`）。
- `cd client-web && npm test && npx tsc --noEmit && npm run build` 全绿；3D 交互回归 `npx playwright test --project=war tests/planet-three.spec.ts tests/industrial-development.spec.ts --workers=2`。
- 截图基线（`belt-visual`、`visual.spec` 的 planet-map-shell）**分支内不更新**，全部合并后由主代理统一重生成。
