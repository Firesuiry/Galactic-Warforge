# 科技树与建造前置

> 本文由 `python3 scripts/gen_tech_tree_doc.py` 从服务端权威目录（`cmd/catalogdump` +
> `server/data/*.yaml`）生成，**不要手改**；改数据后重跑脚本。

## 1. 判定规则（代码口径）

| 规则 | 语义 | 代码 |
| --- | --- | --- |
| 建筑解锁 | 玩家**已完成**的任一科技在 `unlocks` 里声明了该建筑即可建（any，不是 every） | `gamecore.CanBuildTech` |
| 配方解锁 | 配方无任何科技门控 = 基础配方开局可用；有门控则任一已完成即可用 | `gamecore.CanUseRecipeTech` |
| 研究前置 | 科技的 `prerequisites` **全部**完成才能开始研究 | `model.PlayerTechState.HasPrerequisites` |
| 开局预完成 | `dyson_sphere_program`（开局即视为已完成，1 级） | `model.DefaultCompletedTechs` |
| 研究站 | 开始研究需至少 1 台**运行中**的研究站（`matrix_lab`/`self_evolution_lab`，未设配方） | `gamecore.runningResearchLabs` |
| 研究耗材 | 矩阵物品必须装在研究站里（不是背包），按 `research_per_tick` 消耗；多站并行 | `gamecore.researchThroughput` |
| 研究成本 | 目录成本 × 本局 `pace_research`（四舍五入、下限 1）；可重复科技按 `cost_per_level` | `model.ScaledResearchCost` |
| 隐藏科技 | 无公开价值且无可见后继的科技自动隐藏；`hidden: true` 需先持有触发物品才可研究 | `model.ensureTechCatalogDerived` / `gamecore.hiddenTechDiscovered` |
| 建造范围 | 任一己方 `build_radius>0` 建筑半径内，或机甲 `operate_range` 内；否则需 `auto_approach` 派机甲走过去 | `gamecore.requireBuildRange` |
| 建造扣料 | 下单即从**机甲背包**校验并预留全部造价（不是从仓库扣）；仓库要先用 `transfer`/皮带/机器人送进背包 | `gamecore.reserveConstructionMaterials` |
| 拆除退款 | 可建造建筑默认允许拆除，返还 50% 造价（`demolish.refund_rate`）；基地 HQ 不可拆，拆地基恢复原地形，仓库要先卸配送器 | `model.BuildingDemolishRuleFor` / `gamecore.execDemolish` |
| 建造并发 | 玩家 `executor.concurrent_tasks`（默认 2）+ 每 8×8 区域 `construction_region_concurrent_limit`（默认 4，`mass_construction` 每级 +1）；超限只是排队 | `gamecore.constructionRegionLimitFor` |
| 围死校验 | 建造不能把任何地面单位关进无出口的连通区（会拒绝并回执单位名/坐标） | `gamecore.buildingEnclosure` |
| 地形 | 占地每格必须可建（`foundation` 与熔岩上的地热站例外） | `gamecore.build_commands.go` |
| 垂直叠层 | 研究站/生产建筑可在同类型地面建筑上叠层，上限 = 1 + `vertical_construction` 已完成级数；共享底层库存 | `gamecore.resolveVerticalPlacement` |
| 高架传送带 | 只有 3 种传送带可架到 1–4 层，占 1 格，必须有明确方向 | `gamecore.build_commands.go` |

> UI 入口：科技树页 `/tech` **只读**（看前置/成本/解锁与 `leads_to`）；真正下 `start_research`
> 在行星页的「研究与装料」卡片，研究站里装好矩阵后选科技开始。CLI 用 `start_research <tech_id>`。

## 3. 科技树

共 147 条科技定义：可见 144 条、隐藏 3 条。
等级（`level`）只是目录排序字段，真正的依赖看 `前置` 列；同一科技的所有前置都完成才能研究。

### 3.0 主线主干（开局 → 任务完成的最长前置链）

电磁学 → 液体储存封装 → 等离子萃取精炼 → 基础化工 → 高分子化工 → 高强度晶体 → 结构矩阵 → 小型粒子对撞机 → 奇异物质 → 引力波折射 → 行星电离层利用 → 狄拉克逆变机制 → 宇宙矩阵 → 任务完成

这条链上任一科技完成前，它后面的全部科技都锁着；支线科技只是从这条链上分叉出去的节点。
