# 红警向玩法差距分析（2026-09-28，基于 b88f986）

用户目标：做出“戴森球计划 + 红警”的感觉。本文为代码核查结论（非文档转述），按对该目标的影响排序。

## 一句话结论

戴森球那一半（行星内工业）已经很厚；红警那一半（实时战斗、会打过来的敌人、一局完整对抗）基本仍是空壳。当前更像“带战争数据的工厂模拟器”。

## 已核实的关键缺陷

- `move` 瞬移：路径校验后直接改坐标（`gamecore/rules.go` `execMove`）；`attack` 一次性扣血，单位不自动索敌/还击。
- 小队无坐标，不在编队时交战距离 `1<<30`（`gamecore/runtime_fleet_settlement.go:398`），全图可打；小队与舰队永不被摧毁，且只能打黑雾，不能打玩家。
- 黑雾位移 `int(0.01*…*cos)` 恒为 0（`model/enemy_force.go` `SpreadEnemyForce`）；强度不增长；袭击只打“离地图中心最近”的建筑，伤害先减 HP/10（`gamecore/enemy_force_settlement.go` `executeEnemyAttack`），满血建筑≈0 伤害。
- 部署消耗 `ReadyPayloads`（军工队列产出），制造台按配方造的同名载荷物品不被消耗——两套并行生产，一套是装饰。
- 战斗科技只作用于执行体，对炮塔/小队/舰队无效。
- 活动行星是 `GameCore` 全局单值（`gamecore/core.go:514`），`switch_active_planet` 会切换所有玩家；淘汰判定只看活动行星。
- 所有地图 `system_count: 1`；行星 runtime 只在启动时创建，运行中无法殖民新行星。
- 单人配置第 1 tick 即判胜（`gamecore/rules.go` 仅剩一人即胜）；判胜后游戏继续运行，Web 只弹 toast；`/rollback`、`/save` 无管理员权限。
- Web：单选单位（`planet-map/store.ts`）、无框选/右键指令/编队/攻击移动/集结点；`damage_applied` 被刻意不提示（`notifications/event-toasts.ts`），无“基地遭受攻击”；3D 模式无小地图、战斗特效、血条；`fetchPlanetPath` 未使用，远处建造需手动分段走机甲；无蓝图复制/拖拽铺带/区域操作/非皮带旋转；无音乐。

## 差距与优先级

### P0 没有就没有“红警感”

1. **实时战斗层**：逐 tick 移动+寻路、自动索敌与还击、攻击移动/巡逻/停止、单位与小队有坐标并会死亡、部队对部队（含 PvP）。
2. **会打过来的敌人**：黑雾巢穴成长，威胁随玩家能耗/产能上升（DSP 黑雾逻辑），沿路径波次进攻，优先袭击矿区/物流线/电厂。这是“建工厂 vs 守工厂”张力来源。
3. **遭遇战 AI 对手**：服务端确定性 bot（采矿→建基地→出兵→进攻，分难度）；LLM Agent 作为可选高阶指挥官，而非唯一对手。
4. **RTS 操作手感**：框选/多选、右键指令、Ctrl+数字编队、攻击移动、集结点、UI 生产队列；3D 战斗特效、血条、炮塔转向；受袭警报+镜头跳转、3D 小地图。

### P1 形成完整一局

5. **对局框架**：新局/遭遇战设置（地图、对手、难度）、胜负结算与重开、团队胜利；修单人即胜、全局活动行星、管理接口权限。
6. **兵种与克制**：装甲类型与克制、兵营/战车工厂/机场/船坞分工、高科技建筑解锁分级、超级武器（戴森射线打击/行星炮天然契合）、墙与门。
7. **工业真正喂战争**：单位=产线成品（合并两套生产）、弹药走皮带/物流、战斗科技作用于全部军事单位；打电厂→炮塔断电（已有基础）、矿区与物流船可被袭扰（对应红警矿车）。

### P2 戴森球后期感

8. **走出母星**：多星系地图、殖民/前哨创建新行星 runtime、跨星系舰队远征。
9. **戴森球材料化**：建壳耗组件与火箭、可视化编辑器，戴森球作为终局能源/超武目标。
10. **表现与氛围**：音乐与 EVA 式语音播报、DSP 式生产统计图表、昼夜/天空可见恒星与戴森球、拖拽铺带/蓝图/区域拆除/旋转、机甲自动走向建造点、加载已有 GLB 模型。

## 建议路线

先做“最小红警闭环”垂直切片：实时移动+自动交战+单位死亡 → 会进攻的黑雾 → 框选/右键/攻击移动+3D 战斗特效与受袭警报 → 遭遇战 bot+结算画面。完成后再做多星系扩张与戴森球终局。
