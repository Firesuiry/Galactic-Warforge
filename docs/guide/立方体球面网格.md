# 立方体球面网格

行星采用唯一的 `cube_sphere` 拓扑，配置 `planet.face_size: N`。服务端保存六个 N×N 面，二维存储图集为 3N×2N，`map_width` / `map_height` 仅表示图集尺寸，不是经纬度或平面世界边界。

面序号 `face = floor(y/N)*3 + floor(x/N)`，面内坐标为 `(x%N,y%N)`：

| face | 法线 | 向右 U | 向下 V |
| --- | --- | --- | --- |
| 0 | +Z | +X | -Y |
| 1 | +X | -Z | -Y |
| 2 | -Z | -X | -Y |
| 3 | -X | +Z | -Y |
| 4 | +Y | +X | +Z |
| 5 | -Y | +X | -Z |

前端以等角立方体球面投影显示：面内 u/v 映射至 [-π/4,π/4]，球面方向为 normalize(N + tan(u)U + tan(v)V)。无经纬度极点汇聚；六面仍存在受控形变，边角为网格接缝。

跨面移动与方向转换统一由球面四邻接图确定。图集里相邻的像素不一定是地表邻居，图集外边缘也不是世界边界。客户端不得对 x/y 做取模、夹紧或直接加减来替代地表邻接。范围、寻路、视野、资源团簇和出生区采用服务端球面图。

状态、行星查询与快照包含 `surface: {topology: "cube_sphere", face_size: N}`。旧 `planet.width/height` 配置和不含球面拓扑的旧存档直接拒绝；新局请使用独立存档目录，不覆盖原试玩存档。默认 N=816，总地块 3,995,136，接近旧 2000² 地块预算。

`GET /world/planets/{id}/scene` 的 x/y/width/height 保持图集矩形裁剪；可同时传 `near_x`、`near_y`、`radius`（0..128）获取以球面图距离计算的邻域补片。`surface_patches` 的每项包含独立 `bounds/terrain/visible/explored`；主 `buildings/units/resources` 合并补片实体并去重。绘制时须按每片的 bounds 读取坐标和迷雾，不能把整个图集连成一个平面网格。

CLI 示例：`scene planet-1-1 0 0 32 32 --near_x 0 --near_y 16 --radius 16`。

## 建造与方向约定

每个地块有 north/east/south/west 四个面内方向。跨边后方向会旋转，传送带出口、分拣器、建筑端口和仓储/电网连接均使用同一套方向运输规则。跨面移动按真实可行走地块寻路，不能穿过不可通行地形或建筑。

多格建筑按锚点的面内偏移运输到相邻面，占据、施工预留、完成、拆除、摧毁及存档恢复均处理全部占地。矩形宽高不能大于面宽；绕立方体角点导致同一建筑自重叠时拒绝放置。建筑蓝图的矩形捕获、旋转与摆放限于单面，以保留唯一的矩形方向语义；单体建筑、物流和单位仍能跨面。

## 可重复验证

在 `server/` 使用项目指定 Go：

```sh
/home/firesuiry/sdk/go1.25.0/bin/go test ./...
/home/firesuiry/sdk/go1.25.0/bin/go test -race ./internal/surface ./internal/visibility ./internal/query ./internal/model ./internal/gamecore
```

在 `client-web/`：

```sh
npm test
npm run build
npx playwright test tests/cube-surface.spec.ts tests/planet-three.spec.ts --workers=1
SW_TEST_MAP="$PWD/../server/testdata/map-cube-poles-large.yaml" SW_CUBE_POLES=1 SW_BACKEND_PORT=19482 SW_WEB_PORT=4174 npx playwright test tests/cube-poles.spec.ts --workers=1
```

极区测试使用独立真实服务端场景：N=256、768×512 图集，两名玩家分别位于北/南极面中心。除真实建造和移动外，还验证局部精细曲面加载和 390px 视图切换。小图可换用 `map-cube-poles.yaml`（N=48）。截图输出 `/tmp/siliconworld-cube-*.png`；地图 fixture 仅用于测试，不注入前端状态或伪造响应。

`server/internal/surface/cmd/fixtures` 生成跨语言几何/方向样例，前端与 Go 共用；Go 自身另以完整 BFS 核对压缩路径距离，不以同实现自证。等角网格仍有有限形变，不承诺整球所有格子都是完全相同的正方形。
