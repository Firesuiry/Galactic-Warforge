# 3D 表现开发指南

## 目标与边界

目标是达到《戴森球计划》式星球工业观感，包含近景机械细节、自然地表、空间尺度、运行动画、光照和清晰操作。后端继续负责生产、物流、战斗、资源与权威坐标；前端仅表现已收到的状态，不增添虚假的建筑、运输任务或可见情报。

当前已完成行星工业表现的一轮重构：原创统一工业资产、材质地表、球面岩地装饰、动态阴影、环境反射、辉光、星空大气、倾斜镜头、建造栏模型缩略图。全球视角与地面视角仍使用同一球面；等面积投影双向对应服务端坐标，避免极区建筑挤压。地形未知区域使用扫描蒙层，不生成猜测的大陆。

## 操作与实现

- 行星页默认 3D；右上可切换平面战术。
- 拖动旋转，滚轮或按钮缩放，俯仰滑条调整镜头；全球视角拉远、聚焦基地返回近景。
- 点击建筑或单位查看详情，建造栏选择建筑后点地表放置；单位选中后点移动，再点目标地表。Esc 和右键取消当前指令模式。
- `planet-three-scene.ts` 负责场景、镜头、输入和后端快照同步，`three/` 分离投影、地表、工业资产与空间表现。
- 工业资产共享模板几何/材质；岩地装饰使用最多 4000 个实例；Three.js 按需加载。冻结截图使用 `?freeze=1`。
- DEV 下 `window.__planetThree.project(tile)` 只辅助定位真实画布点击，验收必须核对真实 POST 与后端最终状态。

## 运行与验证

在仓库根启动隔离战争测试服：

```sh
bash server/scripts/start_official_war_test_server.sh 19481
```

在 `client-web/`：

```sh
VITE_SW_PROXY_TARGET=http://127.0.0.1:19481 npm run dev -- --host 127.0.0.1 --port 4173
npm run build
npm test
SW_SKIP_WEBSERVER=1 npx playwright test tests/planet-three.spec.ts --workers=1
```

浏览器测试使用战争服 p1，验证旋转缩放、详情、建造和移动的请求坐标/响应/后端结果、退出模式、平面与3D切换，并检查页面和 WebGL 错误。测试服状态会改变；重复验收会选择当前可用地块。

## 持续目标

本轮通过功能测试不等于整体美术目标完成。后续仍需以真实截图继续审查：更自然的星球地貌/海洋与工业地景、更丰富且保持权威状态的物流和运转表现、星球到恒星系的视觉连贯性、规模扩大后的帧耗与资源释放、窄屏布局。大型场景和移动设备不能用48×48战争场景的一次成功代替验证。

## 本轮验证记录（2026-09-10）

- 451 项前端单测通过；生产构建通过。
- Chromium 真实战争服建造/移动闭环、桌面视图切换通过，页面与 WebGL 错误为零。
- 390×844、820×900 相机/抽屉/视图切换通过；手机总览默认折叠，通知由顶栏铃铛收纳，避免覆盖建造栏。
- 数学球与局部精细曲面在10000²地图极区经实际Raycaster校验，误差小于当地地格尺寸的2%。
- 浏览器注入1000栋建筑的诊断中，10次生产状态同步平均约1.74ms，对象和动画保持；该数值只证明CPU同步成本，不能作为千栋建筑的整帧GPU性能结论。
