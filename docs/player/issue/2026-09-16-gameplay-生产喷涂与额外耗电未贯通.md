# 普通制造台喷涂属性与额外耗电未贯通

状态：待修复（2026-09-16代码核查）。

喷涂机真实消费增产剂后，物料经皮带到分馏塔时保留喷涂效果；但经普通建筑IO进入制造台时，`StoragePortInput`只接收物品ID和数量。`StorageState.Inventory/InputBuffer/OutputBuffer`均为数量映射，`collectRecipeInputs`构造无Spray的物品堆，所以通用制造未获得皮带上已有的增产剂效果。直接对配方计算函数传入喷涂输入的单元测试不能证明真实运输链已经生效。

相关路径：`server/internal/gamecore/building_io_settlement.go`、`server/internal/model/storage.go`、`server/internal/gamecore/production_settlement.go`、`server/internal/model/production_cycle.go`。

同时，配方`EnergyCost`以及生产奖励计算中的`EnergyConsumeTotal`尚未进入实际电网负载，当前电网只读取建筑runtime耗电与维护消耗。通用生产按实际电力比例减速已修复，不代表增产/加速模式额外耗电已完成。

影响：普通制造的喷涂消耗/额外产物/额外功耗不能形成完整玩法；尚无玩家侧绕过方式。需统一仓储、运输、配方取料与存档的真实物品堆表示，并用真实喷涂→仓储→制造链验证守恒与收益。
