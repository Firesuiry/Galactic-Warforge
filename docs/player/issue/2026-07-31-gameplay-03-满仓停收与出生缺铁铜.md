# 矿机满仓停 minerals + 出生附近无铁/铜，开局科研链二次卡死

- 状态：已修复
- 首次记录：2026-07-31
- 修复日期：2026-07-31
- 来源：试玩验收清单路径 A（API 冒烟，config-dev + map.yaml seed-001）
- 类别：玩法 / 经济系统 / 出生资源 / 发展主线
- 关联：[[2026-07-18-gameplay-02-minerals建造货币零收入发展卡死]]（kickback 首次落地后的二次卡点）

## 问题描述

1. **满仓停收**：`mining_machine` 本地存储容量 48。kickback 原先按「实际入库量」折算 minerals；堆满后 `PreviewReceive` 门控直接跳过开采 → minerals 平台（试玩见 68→80 后不再涨），开局在皮带铺好前再次资金链断裂。
2. **出生缺铁铜**：`seed-001` 默认图出生附近常见 coal/silicon，铁/铜矿在执行体操作距离外。矩阵科研链（铁→磁铁/磁线圈，铜→电路板→电磁矩阵）不可达，A3 路径断在「有矿但不是对的矿」。

## 复现步骤

1. 全新 data_dir 启动 `config-dev.yaml + map.yaml`（seed-001）
2. 建 wind → lab → tesla → mining_machine（任意近处矿）
3. 不运走本地存储，观察 `summary.resources.minerals`：短时上涨后平台
4. 扫描 base 附近 `operate_range` 内资源 kind：可能只有 coal/silicon，无 iron_ore/copper_ore

## 修复内容

- `rules.go` `settleResources`：始终 `mineResource`；`Receive` 尽力入库；**kickback 按 mined**（满仓 stored=0 仍记 minerals）；物品 stats 仅 stored>0
- `collectMineralsKickback` 注释改为「按挖出量」
- `runtime_registry.go`：`seedPlayerOutposts` 在 flatten 后调用 `ensureStarterResourceNodes`，为每个基地在 `spawnMineDistance` 内补齐 `iron_ore` + `copper_ore`（Total=2000, Yield=8）
- 回归：
  - `TestMineralsKickbackContinuesWhenStorageIsFull`
  - `TestT124StarterIronAndCopperWithinMineDistance`
  - `TestConfigDevStarterOresReachableForMatrixChain`
- 文档：`docs/dev/服务端API.md` minerals 规则 + starter 矿种；`docs/player/上手与验证.md` §4.1
