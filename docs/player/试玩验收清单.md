# 试玩验收清单（T-D2）

> 大版本 / 品质冲刺后的**人类试玩脚本**。目标不是替代自动化测试，而是用固定路径回答：
> **从没看过代码的人，能不能用 GUI 打通开局与一场仗？**
>
> 配套：
> - 启动：`docs/dev/本地试玩环境启动.md` / `scripts/start-local-playtest.sh`
> - 玩法说明：`docs/player/玩法指南.md`
> - 详细 CLI 对照：`docs/player/上手与验证.md` §4
> - 命令覆盖：`docs/dev/命令覆盖率矩阵.md`（`python3 scripts/command_coverage.py --check`）
> - 问题记录：`docs/player/issue/`（一个问题一个文件）

## A. 新局 30 分钟体验路径（`config-dev` + `map.yaml`）

> 全程**优先纯 Web**。CLI 仅在 Web 明确卡住时作对照，并立刻记 issue。

### A1. 登录与态势可读（≤3 min）

| # | 步骤 | 通过标准 | ☐ |
|---|---|---|---|
| A1.1 | 打开 `/overview` | 能看到 tick、活跃行星、资源摘要；「下一步」类引导可点 | |
| A1.2 | 打开 `/galaxy` | 星图画布可见；可平移/缩放；能进入恒星系 | |
| A1.3 | 打开 `/planet/planet-1-1` | 地图可见基地/迷雾；初始视角能找到基地（web-10） | |
| A1.4 | 顶栏资源 | minerals / energy 数字可见且与 summary 一致（web-08） | |

### A2. 基建与采矿闭环（≤10 min）

| # | 步骤 | 通过标准 | ☐ |
|---|---|---|---|
| A2.1 | 建造 `wind_turbine`（基地邻格） | 建造卡可选中；点击放置成功；电力 generation > 0 | |
| A2.2 | 电网到矿点 | `tesla_tower` 连到资源带；能选中并放置 `mining_machine` **到资源格**（web-07） | |
| A2.3 | 矿物产出 | 等待若干 tick 后 minerals 或矿机本地存储上升 | |
| A2.4 | 选中建筑信息 | 侧栏能看到本地存储/运行态，无裸开发者堆栈（web-06 / web-14） | |

### A3. 矩阵产线与科研起步（≤12 min）——web-01 回归

| # | 步骤 | 通过标准 | ☐ |
|---|---|---|---|
| A3.1 | 铺矩阵产线 | 冶炼/组装链路可建：磁铁→磁线圈、铁/铜→电路板→电磁矩阵 | |
| A3.2 | 建空 `matrix_lab` | 研究站模式（无 recipe） | |
| A3.3 | 未装料开研 | 「研究与装料」里直接开始研究 → 明确失败反馈（缺矩阵），**不**误报成功 | |
| A3.4 | 装料 | 同一面板把矩阵转入研究站本地存储（`transfer_item`） | |
| A3.5 | 再开研 | `electromagnetism` 进入研究 / 完成后解锁（如 `depot_mk1`） | |
| A3.6 | 产线告警 | 空研究站/空转建筑不持续刷英文噪音（web-13） | |

### A4. 中后期入口可发现（≤5 min，有科技再验）

| # | 步骤 | 通过标准 | ☐ |
|---|---|---|---|
| A4.1 | 物流 | 物流站/槽位配置入口在行星命令面可发现 | |
| A4.2 | 戴森相关 | 发射井 / 弹射器 / 戴森脚手架入口在解锁后可发现（不必本局打完） | |
| A4.3 | 切星 | `switch_active_planet` 在多行星可用时有入口 | |

**路径 A 出口标准**：A1–A3 全勾；A4 有科技则勾，否则记「未解锁跳过」。

## D. 失败时怎么记

1. **先复现**：同一场景、同一账号、记下 tick 与操作序列。
2. **建 issue**：`docs/player/issue/YYYY-MM-DD-<域>-NN-短标题.md`，状态「待处理」。
3. **域前缀**：`web` / `gameplay` / `cli` / `devops` / `tech` / `dyson` / `stats`。
4. **不要**在清单里堆长讨论；清单只勾选 + 链到 issue。

## E. 与自动化的分工

| 层 | 负责 | 不负责 |
|---|---|---|
| `command_coverage.py --check` | 指令是否泄漏在 API | 好不好玩 |
| vitest / go test | 组件与规则正确性 | 人类路径流畅度 |
| Playwright 战争 pure-gui | 官方战争 GUI 闭环 | 新局 30 分钟手感 |
| **本清单** | 手感、可发现性、文案、卡点 | 替代 CI |
