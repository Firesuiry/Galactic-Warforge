## 实施波次

- **W1 目录对齐**（本仓库 develop_tools/dsp-catalog + server/internal/model + mapgen）：物品/资源/配方/科技/建筑成本五线并行，文件互不重叠。验收：catalogdump 计数收敛 + 新增 parity/closure 测试绿 + `go test ./...` 绿。
- **W2 玩法接线**（gamecore）：新增科技效果接线（矿物利用→采集、研究速度、分拣叠加、运输船扩容、垂直建造等）、电力批次 B（地热/蓄电循环/聚变燃料/火电多燃料/昼夜）、采集批次 F（稀有矿脉/硫酸海/植被）、物流边缘批次 G（集装机/堆叠分拣器/管线）、研究站体验批次 C。验收：逐项单测 + e2e。
- **W3 验证**：全量测试 + 目录一致性/闭包测试 + CLI 覆盖 + client-web 浏览器验证 + 文档（服务端API.md/客户端CLI.md/玩法指南）+ note.md。

## 范围定义

"行星内可完成" = 以行星上可获取的原料（矿脉/油苗/水/硫酸海/机甲采集）为种子，仅使用可放置在行星表面的机器，经配方闭包可达的所有物品 + 可研究的科技。

- 机器白名单（19 类）：采矿机、大型采矿机、抽水站、原油萃取站、电磁熔炉、位面熔炉、制造台 Mk.I-II-III、化工厂、量子化工厂、原油精炼厂、分馏塔、微型粒子对撞机、矩阵研究站、能量枢纽（充放电池循环）。
- 排除（太空/黑雾专属）：轨道采集器、射线接收站系 → 因此临界光子链/反物质/宇宙矩阵/黑雾专属材料不可达。
- 种子资源（18 种）：铁/铜/石/煤/硅/钛矿脉，可燃冰、金伯利、分形硅、光栅石、刺笋结晶、单极磁石、有机晶体（稀有矿脉），原油、水、硫酸（可抽取），木材、植物燃料（机甲采集）。

## 冻结数字（来自闭包计算，开发时须以测试守住）

- 行星内可达物品：**428 / 486**
- 行星内生产配方（含建筑合成）：**171**（组件配方 124 中除少数黑雾/太空向 + 建筑配方中行星内可达者）
- 科技节点：**304**（107 科技 + 197 升级计入），其中行星内可研究 **270**；其余需要宇宙矩阵或黑雾材料 → 数据保留、状态标 `gated`。
- 行星内可制造建筑：**59 / 62**（不可达 3 个为黑雾版机器等）。

## 数据结构要点

- 物品：`{ id, zh 名称, 类别(resources/materials/components/buildings...), 堆叠 }`
- 配方：`{ id, zh, 类别, 耗时 s, 输入 {物品:数量}, 输出 {物品:数量}, 可用机器[], locked(初始锁定待科技解锁), mining(开采类) }`
- 科技：`{ id, zh, 类别(technology/upgrade), 前置科技[], 解锁(配方/建筑/效果)[], 研究消耗(矩阵/物品 + 数量), 基础耗时 }`
- 研究消耗以"矩阵秒"结算：DSP 原始数据 in=每点消耗物品数、out=总 hash 点数，实现时按 `hash = out / in 物品数` 折算为每秒消耗速率，等价即可，测试守住等价折算。

## 验收标准（测试守住）

1. 目录一致性测试：本游戏 catalog 与冻结快照逐项一致（物品 428、配方 171、科技 304、建筑 59）。
2. 闭包测试：每个 inPlanet 物品都存在从种子资源出发的生产链（模拟推演可得）。
3. 科技闭包：270 个可研究科技的前置链完整、矩阵消耗均为行星内可产；其余标 gated。
4. 引擎仿真 e2e：从空行星起步，脚本化建设到产出 5 种矩阵并解锁一颗科技，全程 tick 结算无错。
5. 浏览器验证 client-web 可见可操作（建筑放置、配方生产、科技研究界面）。
